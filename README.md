# 绝区零助手（Zenless Zone Zero Pocket）

基于 [BetterGI Pocket](https://github.com/babalae/bettergi-pocket) 架构改造的 **绝区零（Zenless Zone Zero）自动对话** Android 助手。
通过悬浮球在游戏上方做屏幕识别与自动点击，用于自动推进剧情、自动选择对话选项。

> 本仓库由 BetterGI Pocket 改造而来：识别层从「PNG 模板匹配」改为「1080p 归一化坐标 + ML Kit 中文 OCR」，以适配绝区零的对话 UI。

## 功能

- **悬浮球**：授权后以气泡形式显示在游戏之上，可拖动、展开面板
- **屏幕共享**：捕获游戏画面作为识别输入（Android 14+ 可选择单个应用）
- **自动对话**：识别对话界面后自动推进
  - 识别到选项时，右侧区域 OCR 读取选项文字，按关键词决策并点击最下方选项
  - 无选项时点击对话气泡继续
- **长按跳过 + 弹窗确认**：检测到「跳过」按钮时点击；连续短按无效则长按触发跳过（长按会弹出确认弹窗，脚本自动点「确定」）
- **黑屏转场点击**：剧情黑屏转场时自动点击推进
- **启动绝区零**：打开已安装的客户端，可选未检测到时自动启动一次

支持国服官服、国际服、云·绝区零。

## 使用

1. 安装并打开应用，按提示开启**悬浮窗**权限
2. 在系统设置中开启无障碍服务「绝区零助手」（用于模拟点击、判断绝区零是否在前台）
3. 点开悬浮球，打开**共享屏幕**，在系统弹窗中选择绝区零画面
4. 按需打开**自动对话**（及「快速点击跳过」「智能选择选项」）开关
5. 进入游戏剧情对话，助手会自动推进

清理后台后若提示无障碍异常，关闭后再重新打开该服务即可。

## 坐标校准（重要）

绝区零对话 UI 与分辨率相关，识别区域与点击坐标全部使用**相对屏幕的比例**（见 `AutoSkipFeature.kt` 中的 `Box` 常量）。
首次在真机使用前，建议按下面步骤校准：

1. 截取一张绝区零对话界面截图（含右上角 跳过/自动/回顾 按钮 + 底部对话框 + 右侧选项）
2. 对照截图量出各区域的相对比例，替换 `AutoSkipFeature` 中：
   - `TOP`：右上角功能按钮区域
   - `BOTTOM`：底部对话气泡区域
   - `OPTION`：右侧选项区域
   - `CONFIRM`：中央「确定」弹窗区域
   - `CONTINUE_X/Y`：点击推进的位置（对话气泡中部偏下）
3. 选项关键词表在 `app/src/main/assets/recognition/AutoSkip/` 下的三个 json，可按实际文案增删

> 注意：当前比例值为**基于常见竖屏手机（1080×2400 等）的初版估算**，未在真机逐项标定。遇到偏移时按上述步骤微调即可。

## 构建

- 推送到 `main` 分支会自动触发 GitHub Actions 构建 **debug APK**（`.github/workflows/build.yml`），在 Actions 页面的 Artifacts 中下载
- 本地构建需 Android Studio + JDK 17 + Android SDK（API 36.1）：`./gradlew :app:assembleDebug`
- 产物按 ABI 拆分（armeabi-v7a / arm64-v8a / x86_64），真机一般选 `arm64-v8a`
